# AGENTS.md — правила работы в проекте «Нарния»

Файл читают **все** сессии DSH, работающие в этой папке. Держим его коротким:
он подмешивается в контекст каждого агента.

## Кто есть кто

- **Дежурная сессия Telegram** (id `telegram-duty`, профиль `web`, плагин telegram-duty) —
  общается с владельцем через Telegram. В списке `/sessions` её нет, это маршрут по умолчанию.
- **Сессия Web UI** — обычная сессия в браузере (http://127.0.0.1:3080), видна в `/sessions`.
- Сессий может быть несколько; у каждой свой контекст, но общая папка и общий репозиторий.

## Как различать сообщения (просьба владельца)

- Сообщения **из Telegram-дежурной сессии** начинаются со значка **📱**.
- Сообщения **из Web UI** начинаются со значка **🖥**.
- Итоговые ответы владельцу подписываем этим значком в первой строке; внутренние
  сообщения агентам можно не подписывать.

## Зоны ответственности (текущее разделение)

| Зона | Кто ведёт |
|---|---|
| `game/content/**`, `game/scripts/**` — разбор книги, подписи, приёмка | Web UI |
| `game/src/**`, `game/tests/**`, `game/e2e/**`, `game/tools/**`, `game/*.json` (конфиги) | Telegram-дежурная |
| `game/HANDOFF.md`, `game/ENGINE.md`, отчёты в `content/*.md` | тот, кто менял код; перед уходом — обновить |

Правило простое: **чужие файлы не переписываем молча.** Понадобилось — пишем в `HANDOFF.md`
и говорим владельцу.

## Обязательные проверки перед коммитом

```bash
cd Narnia/game
npm run check          # typecheck + 103 юнит-теста + сборка
npm run e2e            # 6 сценариев в браузере (Playwright уже скачан)
python3 scripts/validate_content.py   # приёмка контента (если менялся контент)
```

- После правок контента: `npm run content:build` → затем `npm run golden:gen`
  (золотые пути зависят от контента) → тесты.
- Публикация: `npm run deploy` (собирает и пушит в ветку `gh-pages`).
  Сайт: https://sovfir.github.io/narnia-solo-game/ — репозиторий и сайт **публичные**,
  внутри полный текст книги (владелец решение подтвердил, права — у правообладателей).
