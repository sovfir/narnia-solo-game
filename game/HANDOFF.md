## Как запускать

```bash
cd Narnia/game
npm install --cache ./.npm-cache    # ~/.npm недоступен на запись, нужен локальный кеш
npm run dev                          # http://127.0.0.1:5173
npm test                             # 65 тестов
npm run typecheck
npm run build && npx vite preview    # прод-сборка
npm run content:build                # пересборка контента из texts.md + приёмка
npm run golden:gen                   # перегенерировать золотые пути (после правок контента)
```

1. **Режим проверки отметок у кнопок (`mode`).** Исправлено этой ночью: парсер давно помечал
   «проверь ключ 6, 19, 22 **или** 23» как `any`, но сборщик этот режим терял, и движок требовал
   все четыре отметки. Из-за этого были недостижимы узлы 468 → 509 → 412 → 243 (целый финал).
   Теперь `mode` доходит до движка (`Choice.mode`), финал 243 покрыт золотым путём.
   Стоит проверить остальные 4 места с «или»: 3Б (25), 6Б (18) — там одна отметка, режим не важен,
   и 220 (38, 39, 40, 41, 44, 45) — уже `any`.
2. **three.js (Фаза 4–5):** кубики с анимацией и объёмная карта. Сейчас кубики — числа в DOM,
   карта — CSS-сетка (2D-фолбэк из §8.4 уже фактически есть).
3. **PNG-иконки для PWA.** Сейчас одна SVG-иконка; для некоторых установщиков нужны 192/512 px PNG.
4. **E2E:** Playwright не подключён (в дизайне — Фаза 0/3). Юнит-тесты UI есть.
6. **Контент (её зона):** 10 «спорных» подписей из `AUDIT_labels.md`, 9 осиротевших узлов помечены
