Сцены длиннее ~700 символов подаются страницами по границам предложений

для длинных сцен — оценка «≈ N мин чтения». Кнопки выбора появляются, когда текст дочитан.

E2E нашёл здесь две ошибки, которые юнит-тесты не видели: оверлей броска закрывался сам

### Тесты: 87 юнит-тестов в 16 файлах + 3 e2e, все зелёные
- ядро: кубики (распределение 2d6 на 120k бросков), герой, условия, эффекты, карта, движок;

### E2E в настоящем браузере
`npm run e2e` (Playwright + Chromium, профиль Pixel 5) проходит путь игрока на собранном
приложении: сплэш → меню → герой → сцена 317 → ход → лист персонажа → перезагрузка страницы →
«Продолжить» восстанавливает партию → экран «Сохранения». Консольных ошибок нет.
Скриншоты каждого шага — в `test-results/` (в git не попадают).

Первый прогон E2E сразу нашёл баг, который не видели юнит-тесты: заглушка «Загрузка…»
из `src/main.tsx` оставалась в DOM рядом с приложением (preact дописывает, а не заменяет).
Исправлено через `root.replaceChildren()`.

### Сборка и PWA
`npm run build` собирается: стартовый JS ~19 КБ gzip, CSS 2 КБ, контент (`nodes.json` 145 КБ gzip,
`squares.json` 6.8 КБ) — отдельными чанками. Проверено `vite preview`: `index.html`, JS и JSON
отдаются с кодом 200.
PWA (`vite-plugin-pwa`): `manifest.webmanifest` (standalone, тема, иконка `public/icon.svg`),
service worker с precache 10 файлов (699 КБ) — контент кешируется, игра работает офлайн.

## Как запускать

```bash
cd Narnia/game
npm install --cache ./.npm-cache    # ~/.npm недоступен на запись, нужен локальный кеш
npm run dev                          # http://127.0.0.1:5173
npm test                             # 65 тестов
npm run typecheck
npm run build && npx vite preview    # прод-сборка
npm run content:build                # пересборка контента из texts.md + приёмка
npm run golden:gen                   # перегенерировать золотые пути (после правок контента)
npm run e2e                          # Playwright: браузер уже скачан в .playwright-browsers
npm run e2e:install                  # если браузера нет (ставится локально, ~95 МБ)
```
