## Как запускать

```bash
cd Narnia/game
npm install --cache ./.npm-cache    # ~/.npm недоступен на запись, нужен локальный кеш
npm run dev                          # http://127.0.0.1:5173
npm test                             # 65 тестов
npm run typecheck
npm run build && npx vite preview    # прод-сборка
npm run content:build                # пересборка контента из texts.md + приёмка
npm run golden:gen                   # перегенерировать золотые пути (после правок контента)
```
